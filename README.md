# Pokéarchivo
Página React con nueve Pokémon de Kanto y fichas interactivas. Datos e ilustraciones de https://pokeapi.co, guardados localmente para evitar depender de la API en cada visita.

## Desarrollo
npm install
npm run dev

## Comprobación
npm run build
npm run lint

## Vercel
El proyecto incluye vercel.json. Desde esta carpeta, inicia sesión con npx vercel login y publica con npx vercel --prod. También puedes importar el repositorio en Vercel seleccionando Vite, comando npm run build y carpeta de salida dist.

Proyecto de fans, sin afiliación con Pokémon. Las fuentes de Google requieren conexión; hay fuentes alternativas del sistema.
